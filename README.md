## 🚀 Featured Projects

### 🏥 [MediCore — Patient Management System](https://github.com/FardinAhasanDev/CoreDataBaseFirstCRUDUsingSP)

An ASP.NET Core 9 MVC application demonstrating a **Database-First** workflow and SQL Server **Stored Procedure** integration.

- Patient records with create, update, delete, search, filter, sort, and pagination functionality
- Doctor assignment, prescriptions, profile image uploads, and reporting
- SQL Server stored procedures and table-valued parameters for prescription data
- Responsive Razor views and Bootstrap interface

**Stack:** `C#` · `ASP.NET Core 9 MVC` · `EF Core` · `SQL Server` · `AJAX` · `Bootstrap`

[**View MediCore Repository →**](https://github.com/FardinAhasanDev/CoreDataBaseFirstCRUDUsingSP)

### 💊 [MedPlus — Pharmacy E-Commerce & POS](https://github.com/FardinAhasanDev/Medplus_E-Commerce_Site)

A pharmacy-oriented web application combining e-commerce workflows with inventory and point-of-sale functionality.

- Server-rendered application using Express.js and EJS
- MongoDB data access through Mongoose
- Session-based application functionality and file uploads
- WebSocket integration for real-time application features

**Stack:** `Node.js` · `Express.js` · `MongoDB` · `Mongoose` · `EJS` · `WebSocket`

[**View MedPlus Repository →**](https://github.com/FardinAhasanDev/Medplus_E-Commerce_Site)
